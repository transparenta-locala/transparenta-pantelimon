🏛️ Despre proiect

Monitorizare cetățenească automată a achizițiilor publice ale Primăriei Pantelimon

Ce este acest proiect

Transparența Pantelimon este o inițiativă civică independentă care monitorizează automat contractele și achizițiile publice ale Primăriei Pantelimon (CUI 4420759, județul Ilfov).

Un script Python rulează lunar, descarcă datele publice din SEAP și ANAF, aplică algoritmi de detecție pentru pattern-uri de risc și generează un raport HTML publicat automat pe GitHub Pages.

Site: transparenta-pantelimon.eu
Raport semnale: raport_transparenta.html
Cod sursă: github.com/transparenta-locala/transparenta-pantelimon

Cine suntem

Proiectul este inițiat de un cetățean din Pantelimon, membru USR Pantelimon. Este independent de autoritățile publice și nu este un proiect oficial al partidului.

Conflict de interese: Autorul nu are, la data publicării, niciun contract, relație de angajare sau interes financiar față de Primăria Pantelimon sau furnizorii menționați în raport. Dacă aceasta se schimbă, vom actualiza această pagină.

Datele afișate sunt fapte publice — interpretarea și concluziile aparțin cititorului.

Metodologie

Surse de date

SursăDate extraseFrecvență
SEAP (e-licitatie.ro) Contracte directe: titlu, valoare, furnizor, CUI, tip procedură, nr. ofertanți Lunar

Algoritmi de detecție

Scriptul aplică 19 algoritmi independenți. Fiecare generează un flag cu severitate CRITIC, MAJOR sau MEDIU:

FlagCe detecteazăBază legală
ACHIZITIE_DIRECTA_PESTE_PRAGContract individual peste pragul categoriei: 270.120 RON produse/servicii sau 900.400 RON lucrări, fără TVAL98/2016 art.7 alin.(5)
FRAGMENTAREAcelași furnizor, titluri similare, valoare combinată > pragL98/2016 art.11
FRAGMENTARE_TEMPORARAFereastră 90 zile, suma sub-prag > pragL98/2016 art.11
OFERTANT_UNICSetul de date indică un singur ofertant; documentația necesită verificareL98/2016 art.2
CONCENTRARE_FURNIZORTop-3 furnizori > 60% / > 80% din valoarea totalăL98/2016 art.2
PROCEDURI_NON_COMPETITIVE> 40% din contracte prin proceduri directeL98/2016 art.7
FURNIZOR_DOMINANTUn furnizor > 35% din totalul contractelorL98/2016 art.57-64
VALORI_IDENTICE_ACEEASI_ZIValoare exact identică la firme diferite în aceeași ziL98/2016 art.11
BURST_CONTRACTE≥ 5 contracte semnate într-o singură zi—
SEMNARE_ZI_NELUCRATOAREContract semnat în weekend sau sărbătoare legală—
CRESTERE_BRUSCA_VALOARERevizie contract cu creștere > 50% de valoareL98/2016 art.221
VALOARE_ROTUNDA_SUSPECTAValori rotunde (multiplu de 10k) — indicator euristic pentru verificareHG 395/2016 art.131
FIRMA_INACTIVAContract cu firmă inactivă/radiată la ANAF sau ORCL98/2016 art.220
FIRMA_NOU_CREATAFirmă cu < 24 luni vechime la data contractuluiL98/2016 art.163
RISC_SISTEMIC_FIRMAFurnizor apărut în ≥ 3 categorii diferite de indicatori—
SEDINTE_EXTRAORDINARE_EXCESIVERată > 25% ședințe extraordinare (HCL)Legea 52/2003 art.7
PUBLICARE_INTARZIATAPublicare contract > 11 zile lucrătoare de la atribuireL98/2016 art.55
Limitări: Algoritmii detectează pattern-uri statistice care necesită verificare, nu dovedesc abaterea, intenția sau vinovăția. Rezultatele fals pozitive sunt posibile. Datele ANAF au un decalaj de 6-12 luni față de realitate. Un contract poate genera mai multe flaguri; de aceea raportăm separat numărul de semnale și numărul de contracte unice. Sumele asociate flagurilor pot avea suprapuneri și nu sunt prejudicii.

Praguri legale folosite

  • 270.120 RON fără TVA — prag achiziție directă produse/servicii
  • 900.400 RON fără TVA — prag achiziție directă lucrări
  • 97% din prag — marjă euristică pentru semnalul „aproape de prag”

Sursa: Legea 98/2016, art. 7 alin. (5), forma consolidată. Pragurile au fost verificate la 13.07.2026.

Indicele euristic de transparență

Indicele 0–100 este neoficial. Fiecare componentă primește un punctaj 0–100, apoi se aplică ponderile: achiziții directe 30%, ofertant unic 20%, ședințe extraordinare 15%, fragmentare 15%, documente publicate 10% și răspunsuri la Legea 544/2001 10%. Ultimele două componente sunt în prezent estimări manuale, nu măsurători automate.

Date deschise

Toate datele generate sunt publice:

  • JSON flags: raport.json — toate semnalele detectate, structurat (schema v1.0)
  • Contracte: contracte.json — toate contractele extrase din SEAP
  • RSS/Atom feed: feed.xml — top 20 semnale noi, compatibil Feedly/Inoreader
  • Raport HTML: raport_transparenta.html — raport complet, printabil ca PDF

Cum poți contribui

Dacă ești cetățean

  • După verificarea documentelor originale, trimite o sesizare la ANAP sau Curtea de Conturi dacă semnalul este relevant (butonul 📧 Sesizare ANAP de pe fiecare card pre-completează emailul)
  • Distribuie raportul jurnaliștilor locali sau pe rețele sociale
  • Solicită informații suplimentare de la primărie în baza Legii 544/2001

Dacă ești developer

  • Deschide un Issue pentru bug-uri sau idei noi
  • Trimite un Pull Request — vezi IMPROVEMENTS.md pentru roadmap
  • Fork-uiește pentru altă localitate — codul funcționează pentru orice CUI de primărie:
    git clone https://github.com/transparenta-locala/transparenta-pantelimon
    Editează configurația din monitor_pantelimon.py (secțiunea CONFIG)

Dacă ești jurnalist

  • Datele sunt disponibile ca JSON (raport.json) și RSS (feed.xml)
  • Metodologia completă este documentată pe această pagină și în codul sursă
  • Contact: GitHub Issues
